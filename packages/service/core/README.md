# @contfu/svc-core

Shared types for Contfu.

Provides TypeScript types and constants used across Contfu: source configuration, collection schemas, field mappings, filter expressions, flow definitions, quota limits, and incident types.

## Installation

```sh
npm install @contfu/svc-core
```

## Usage

```ts
import { CollectionSchema, SourceConfig, FlowDefinition } from "@contfu/svc-core";
```
